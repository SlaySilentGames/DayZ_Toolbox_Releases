# DayZ Toolbox - Downloads

DayZ Toolbox lets you change how your DayZ server plays (loot, weather, infected, starting gear, spawn points and more) in plain English, without touching config files. Made for Nitrado servers, console first.

## Download

Go to **[Releases](../../releases/latest)** and download `DayZ_Toolbox_Setup_<version>.exe`, then double-click it.

- No administrator rights are needed.
- Windows may say *"Windows protected your PC"* because the program is new: click **More info**, then **Run anyway**.
- Once installed, the toolbox updates itself: it checks here when it starts and offers each new version.

Every release also has a `.sha256` file: the installer's fingerprint, which the built-in updater checks before installing.
